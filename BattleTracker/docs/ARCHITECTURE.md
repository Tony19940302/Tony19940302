# 架构

| 模块 | 职责 |
|---|---|
| 阵法与战斗布局 | 读取阵法配置及按视角标注的坐标。提供人物号位、宠物槽位及主人映射。 |
| 战斗状态引擎 | 按事件更新人物计数和额度、宠物实例与状态。独立于视频解码和视觉识别。 |
| 事件记录 | 保存事件身份、证据和修订信息，重载时重放有效事件。官方快照表示已到达的状态基线。 |
| 视频检查 | 读取源视频及帧时间，输出元数据和截图。结果可作为之后的标注依据。 |
| 验证入口 | 执行 Phase 0/1 的配置、核心逻辑和视频检查，报告每项状态。 |

后续从详细录像生成候选参考事件，从普通录像提取动作特征。二者通过经复核的行动锚点对齐。识别器输出统一事件结构，调用方以相同方式保存和复盘。技能、事件和资源状态均可通过原始视频时间回溯。

参战视角只读我方气血、魔法和怒气条。敌方用药依赖施法动作、可见的效果与飘字，敌方召唤依赖人物动作、提示与固定宠位入场。详细回放只为离线评估提供参考值。遮蔽回放状态条可复测对敌方条形读数的依赖，实际参战画面需要独立校准。见 [G17](GAME_RULES.md)。

引擎按回合与源时间重放。相同时间戳下，可信开局先于动作，官方快照在动作后结算。调用方为同一动作复用事件 ID。独立官方快照通过绝对值校准，也可以保留覆盖事件的 ID 供回溯。撤销视觉事件后，快照仍保留已确认资源值。跨快照移动已关联的动作时，须在同一批次修正关系。未知基线只累计观测增量。

确认的孩子出战使用 `SUMMON_CHILD`，记录独立孩子实例。每名人物上限 1 次，未获有效证据时已用次数未知。确认一次成功出战即可确定已用 `1/1`。若能确定画面位置，可显式附带主人的固定宠位。孩子和宠物状态分别由各自的入场、离场证据维护。见 [G18](GAME_RULES.md)及[孩子账本回归](../tests/test_battle.py)。

用药视觉候选以施放者为单位整理相邻回复轨迹，保留各接收者和出现时间。多个候选接收者可能来自一次群体施药，也可能来自相邻动作。未确认的关联保持 `UNKNOWN`，已确认的计次用药按一次施放记录。复活与后续回复保留各自的动作证据。见 [G04](GAME_RULES.md)及[群体治疗动作复核](../data/annotations/human-review-04.json)。

`USE_MEDICINE` 的 `payload.medicine_consumption` 可记录 `charged`、`waived` 或 `unknown`。未填的旧记录按计次处理。免扣动作保留身份与效果，净药次为 0。已确认施药而扣次待定时，`medicine_used` 只表示已确认用量的下界，精确剩余未知。有效数字快照或对动作的修订可恢复精确剩余。详细版暂时显示的瓶数按观察证据保存，稳定读数用于药次评估。见 [G30](GAME_RULES.md)及[复评](../outputs/phase-06/medicine-skill-separation-20261125/施药动作与免扣药次复评.md)。

详细录像提取报告绑定原始读数的 SHA-256。单独的离线结算入口只对已复核的免扣动作检查同一主人由暂增到跨回合回落的稳定读数。结果另存，读不到的瓶数区间继续保留。见 [详细版复评](../outputs/phase-06/medicine-counter-settlement-20261126/详细版暂记药次复评.md)。

离线试验可用 `medicine_recover_cyan_overlap` 续接与青光相连的回复数字。原有上升轨迹只续接原受益范围内唯一对应的分离读数。首段较短或上升不足时，至少两个连续帧补读点及足够上移支持后再接入，补出的轨迹断开后重新识别。施药者按独立动作证据判定。见 [自动定位复评](../outputs/phase-06/medicine-auto-glyph-20261126/自动定位绿字补读复评.md)。

离线选项 `medicine_check_pet_body` 对弱起点补回的回复轨迹复核施药动作。仅当动作首选宠位在起手前至少四个可读帧持续缺乏本体纹理，才重算候选。关联技能、已知近期出战和录像覆盖范围参与判断。结果是施药者选择的证据。见 [宠位复评](../outputs/phase-06/medicine-pet-presence-20261126/宠位本体与施药归属复评.md)。

视觉布局中 `players` 和 `pets` 的键标识原校准坐标。`formation_slots` 分别记录人物和宠位的阵法号，`verified_pets` 标识已核实主人的固定宠位。用药和召唤先用原坐标识别动作，再用同侧阵法号连接已确认的宠位与人物。预测保留原画面键，另附已校准的 `formation_slots`。未核归属时保留候选及可确认的受益者。离线片段索引可通过 `--vision-layout` 复用这项校验，配置须绑定同一普通录像。见 [左方站位复评](../outputs/phase-06/formation-identity-left-20261126/左方站位与归属复评.md)。

离线选项 `summon_vacant_beam` 在敌方宠位检测从低纹理到稳定新外观的变化。固定宠位需要出现连续的强金色光柱，对应人物需要有起手动作，光柱散去后需要持续的本体纹理。候选等待约 1.52 秒的后续画面后才发布，并与重叠的原有召唤证据去重。程序将它作为待复核候选。见 [弱金环出宠复评](../outputs/phase-06/summon-weak-ring-20261126/弱金环出宠复评.md)。

结合 `summon_vacant_beam` 开启离线选项 `summon_beam_return` 后，可以复核未及时在原位稳定的新宠。程序在强光柱前后保存名字字形，要求有连续空位和回位后的稳定模型，并复查更早的同名字形及中途第二轮强光柱。回位路径等待约 2.24 秒及下一帧，优先保留已有候选。见 [入场后回位复评](../outputs/phase-06/summon-return-20261127/入场后回位复评.md)。

离线复核入口 `tools/apply_child_reviews.py` 用已确认的回放身份、复核片段指纹、人物、宠位及入场时间关联孩子候选，输出独立复核后的事件。修订记录保存原预测类别及入场宠位。视觉判定和已确认标注分别保留原始证据。见 [孩子入场与宠次复评](../outputs/phase-06/child-entry-20261127/孩子入场与宠次复评.md)。

参战模拟离线选项 `summon_guard_retained` 在已核实主人的宠位比较疑似召唤前后的名字字形和本体颜色。前后需有连续匹配，贴近光效前需见到同一外观，名字匹配中断最多 550 毫秒。弱候选满足条件时改为 `UNKNOWN` 并保存对应帧及可判定时间。仍具独立入场证据的候选保留。此复核在用药判定后执行。见 [原宠留场复评](../outputs/phase-06/retained-pet-20261127/原宠留场复评.md)。
