# 需求与验收边界

- Phase 0 建立项目、轻量验证流程、资料清单、业务规则库和分阶段验收计划。
- Phase 1 支持八种阵法的逻辑站位和统一的宠物归属。业务状态随有效事件重放，支持被修订的事件、动态额度、官方快照和未知初始值。
- 视频检查在本地输出元数据、文件校验值、按源时间定位的画面及抽帧索引。
- 视觉阶段须使用经复核的参考数据，评估事件类型、人物或宠物行动者、资源归属、时序及累计误差。关键技能和实际出手顺序可用时间线保存，靴子图标含义仍待独立验证。
- 长期产品覆盖 Windows 与 Android。阶段授权、详细交付和适用约束见 [原始方案](../PROJECT_SPEC.md)。
