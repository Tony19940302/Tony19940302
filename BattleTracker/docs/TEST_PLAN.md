# 测试计划

## Phase 0/1

运行 `python tools/verify.py --profile phase-01`。覆盖以下行为，具体测试及诊断以实际报告为准。

- T01 阵法配置及两队五个人物与固定宠位的归属，包含龙飞阵、未知坐标和外部标注数据。
- T02 人物用药记到本人，宠物用药记到其主人。同一回合的多次独立事件分别计数，受药对象保持自身用药计数。相邻多受药候选保留各目标与时点，归并待核时保持未知。
- T03 冻结宠物槽位，区分开局已出场、成功召唤、离场、死亡和复活。验证孩子单独计次、每人一次和原宠次核对。
- T04 可靠初始值、未知基线、动态上限、官方快照及非法资源数据。
- T05 候选、重复提交、撤销、修正、反复重放及持久化往返均保持一致。
- T06 验证视频哈希、解码元数据、源时间戳抽帧、指定时间边界和异常输入。

## 视觉与跨端

统计每次预测与人工参考的一对一匹配，保存误报、漏报、归属错误和证据位置。时间容差须实测，参考不确定时保留标签状态。分比赛留出独立测试，报告每回合和整场累计资源误差。Windows 和 Android 复用相同的输入事件与期望账本验证业务一致性。
