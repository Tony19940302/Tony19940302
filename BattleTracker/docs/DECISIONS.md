# 架构决策

| 编号 | 决策 | 原因 |
|---|---|---|
| D01 | 业务核心使用可序列化事件及确定性重放。 | 修订或撤销后可重算状态并保留审计线索。 |
| D02 | 宠物槽位和宠物实例分别建模。 | 换宠后原主人的归属关系继续适用。 |
| D03 | 用可靠基线计算绝对已用值。额度和值均可为未知。 | 截断录像与标准开局的可观察范围不同。 |
| D04 | 阵法逻辑顺序和屏幕坐标分别保存。 | 实战两侧的投影布局需要分别校准。 |
| D05 | 官方计数器作为观察值，对齐后再用于校准。 | 回放速度、跳帧及两份录像的起点都可能不同。 |
| D06 | 数据按整场比赛划分。 | 同一场的不同视频和片段含有重复事件。 |
