# Phase 0/1 独立审查

| 审查发现 | 修正和回归验证 |
|---|---|
| 官方快照关联宠物实例时，预先校验无法解析已出场宠物的主人 | 在回放到达快照时校验，使用关联动作发生时解析出的归属 |
| 撤销被快照覆盖的识别事件时，原先会拒绝修订 | 保留官方绝对计数并输出未解析的关联标记 |
| 将已被快照覆盖的动作移到快照之后会让计数重复 | 拒绝冲突的修订，允许在同一批次同步修改快照关联 |
| 可将已退场或已替换的实例复活，或让旧实例继续施药 | 复活要求当前槽位的倒地实例，显式宠物施药要求当前在场实例 |
| 快照关联使用元组时，JSONL 往返后再次录入会误报冲突 | 录入时规范化 JSON，并验证保存、重载和幂等重试 |
| 第二次开局事件可以重置既有消耗 | 开局事件仅可在回放首位生效，并验证失败更新不改变状态 |

独立复验结果为 26 项测试通过，依赖校验通过，已知的两个素材哈希校验通过，三个缺失素材条目为 SKIPPED。见 [独立报告](../reports/phase-01-independent.json)。
