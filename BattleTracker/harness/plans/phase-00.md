# Phase 0 · 项目初始化和验证

## 目标

盘点并核验素材，建立项目导航、依赖、规则库及阶段报告。

## 范围

仓库、Python 环境、素材清单和统一验证入口。

## 非目标

识别、标注、训练和产品界面。

## 依赖

本地项目目录、Python、已有素材。

## 任务

初始化 Git；盘点依赖、硬件和原始资产；保存文件哈希；创建知识库和阶段计划；运行配置和视频读取检查。

## 验收标准

已知素材可读取，资料状态可追溯，项目可安装并运行统一验证。

## 验证命令

`python -m pip install -e ".[test]"`；`python tools/verify.py --profile phase-01`

## 已知风险

指定录像缺失时记录缺口，任何替代样片单独标识。

## 完成证据

依赖锁定记录、资产清单和 phase-01 实测报告。 当前状态见 [阶段进度](../../docs/PROJECT_PROGRESS.md)。
