# phase-development

1. Read `AGENTS.md`, the relevant phase plan, and affected rules and decisions.
2. Build within the authorized stage. Check assumptions against code or source evidence.
3. Run the stage verification command and inspect each status. Resolve failures or capture the exact blocker and attempted fixes.
4. Update the progress, known issues, and build log with artifacts. Leave later phases at their verified status.
